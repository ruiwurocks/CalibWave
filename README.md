# CalibWave

MATLAB tools for acoustic-emission sensor calibration, waveform extraction, waveform/FFT visualization, and sensor-sensitivity estimation.

## Setup

Run this once in MATLAB before launching apps:

```matlab
setupCalibWave
```

## Apps

The App Designer entry points live in `apps/`:

- `AECalibrationMainApp`
- `SensorArrayEditor`
- `CalibrationParameterEditor`
- `WaveformViewer`
- `FFTViewer`
- `SensorSensitivityViewer`

## Data Policy

Large example data, calibration resources, presentations, animations, and generated exports are intentionally excluded from GitHub:

- `examples/`
- `resources/`
- `Presentation/`
- `Animation/`
- `ExportedFigures/`

Keep those folders local or distribute them separately.
